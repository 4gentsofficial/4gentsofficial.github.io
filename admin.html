How publishing works

  1. Create or edit stories here.
  2. Tap Export news.json. Your phone downloads the latest data file.
  3. Open GitHub → 4gentsofficial/4gentsofficial.github.io.
  4. Tap Add file → Upload files and upload the new news.json.
  5. Tap Commit changes. Wait about 1–2 minutes and refresh your website.

This admin page does not contain a password and does not directly change GitHub. Your GitHub account remains the thing that controls what gets published.
